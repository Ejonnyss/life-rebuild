# LIFE: REBUILD

Мобильная игра о реальных шагах. При первом запуске объясняет правила, предлагает выбрать до трёх целей, желаемый результат и главную помеху. Для каждой цели показывает последовательность этапов, причину и проверяемый результат каждого действия. На главном экране предлагает одну основную миссию и до двух альтернатив с учётом сил и времени.

Маленький подготовительный шаг записывается, но не закрывает большой этап. Пройденные этапы и реальные показатели видны отдельно от игрового опыта. Пропуски не отнимают опыт. План и цели можно изменить в профиле. В нём же можно снова открыть инструкцию.

## Разработка

```sh
npm install
npm run dev
```

Проверка перед публикацией:

```sh
npm test
npm run lint
npm run build
```

Сборка лежит в `dist/`. После сборки скрипт добавляет в service worker все файлы приложения для работы без сети. Данные пользователя хранятся в `localStorage` конкретного браузера. Данные версии 1 сохраняются: при обновлении приложение предлагает настроить новый маршрут, не стирая журнал и опыт. Код не содержит личного профиля, аналитики и ключей сторонних сервисов.

## Резервная копия

В приложении: «Профиль» → «Скачать копию». Копию можно восстановить в профиле или на первом экране после очистки данных. Импорт проверяет формат и размер файла.
