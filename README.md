# LIFE: REBUILD

Мобильная игра о реальных шагах. Работает локально в браузере: предлагает одну основную миссию, позволяет уменьшить шаг, учитывает силы и время, сохраняет прогресс и делает резервную копию.

## Разработка

```sh
npm install
npm run dev
```

Проверка перед публикацией:

```sh
npm test
npm run lint
npm run build
```

Сборка лежит в `dist/`. После сборки скрипт добавляет в service worker все файлы приложения для работы без сети. Данные пользователя хранятся в `localStorage` конкретного браузера. Код не содержит личного профиля, аналитики и ключей сторонних сервисов.

## Резервная копия

В приложении: «Профиль» → «Скачать копию». Копию можно восстановить в профиле или на первом экране после очистки данных. Импорт проверяет формат и размер файла.
